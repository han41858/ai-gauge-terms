## English

AI Gauge is a Chrome extension that shows usage, reset times, and plans for ChatGPT, Claude, Gemini, and Grok in one place.

It runs entirely in your browser with no ads and no separate server. Available in English and Korean.

### Key features

- Usage, limit reset times, and last update time for each service in the popup
- Usage gauge below the ChatGPT, Codex, Claude, Gemini, and Grok input boxes (can be turned off per service)
- Toolbar usage display for the current tab, with customizable caution and warning colors
- Reset ticket information for supported services (read-only)
- Queries through your existing signed-in session, with a local snapshot shared across tabs

### Privacy

AI Gauge does not collect conversations, prompts, or payment information, and contains no ads, third-party analytics, or behavioral tracking. Usage data and settings are kept only in the extension's browser storage and are not sent to any developer server.

See the [Privacy Policy](PRIVACY.md) for details.

## 한국어

ChatGPT·Claude·Gemini·Grok의 사용량, 초기화 시간, 요금제를 한곳에서 확인하는 Chrome 확장 프로그램입니다.

광고나 별도 서버 없이 브라우저에서 동작합니다. 한국어·영어를 지원합니다.

### 주요 기능

- 서비스별 사용량·한도 초기화와 마지막 갱신 시간을 팝업에 표시
- ChatGPT·Codex·Claude·Gemini·Grok 입력창 하단에 사용량 게이지 표시 (서비스별 끄기 지원)
- 현재 탭에 맞춘 툴바 사용량 표시와 사용자 지정 주의·경고 색상
- 지원되는 서비스의 초기화 티켓 정보 표시 (조회 전용)
- 기존 로그인 세션을 통한 조회, 로컬 스냅샷 공유

### 개인정보 처리방침

AI Gauge는 대화 내용·프롬프트·결제 정보를 수집하지 않으며, 광고·외부 분석·행동 추적이 없습니다. 사용량 정보와 설정은 브라우저 확장 저장소에만 보관되며 개발자 서버로 전송되지 않습니다.
